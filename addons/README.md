# Зависимости проекта

`gdUnit4/` — [GdUnit4 6.2.2](https://github.com/MikeSchulze/gdUnit4/tree/0127a55f4543dfc24746f6e5c7ba6f94105d51f2),
MIT; лицензия находится в `gdUnit4/LICENSE`.
Из закреплённого архива перенесён только `addons/gdUnit4`, без изменения
upstream-кода. Godot создал `.uid` и настройки импорта `*.import`.
Версия, commit и SHA-256 архива: [toolchain-lock](../docs/toolchain-lock.json).
Addon включён в редакторе для тестов, но исключён из release-экспорта.
Никакие другие плагины, включая Godot MCP, не подключены.
