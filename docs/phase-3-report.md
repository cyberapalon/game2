# Фаза 3 — поверхность, спуск и «Корни»

Ветка `feat/phase-3-surface-roots` создана от актуальной `main`,
`820be76c7c360667ac5c41232a661c98c2dabd02` (фаза 2).

## Игровой маршрут

```text
Поверхность, 0.00 км: старт → смотритель → обломок → старая шахта
                                                   ↕
Под шахтой, 0.12 км:         лестница ↔ уступы ↔ нора
                                                   ↕
Развилка, 0.24 км:             вход ↔ корневые уступы ↔ выход
                                            ↕           ↕
Тихая нора, 0.27 км:       необязательная находка   Глухой свод, 0.42 км
                                                      ↕
                                               закрытое сплетение
```

На поверхности один NPC, подсказка по близости, E и три реплики без раскрытия
истории. Нет квестов и сложной диалоговой системы. Вход в шахту находится
в конце поверхности, не запускается автоматически. Спуск — затемнение,
движущиеся вверх рёбра шахты, название и новая глубина, затем открытие комнаты.
Комнаты созданы вручную в `.tscn`, без runtime-генерации.

Явные норы/лестница, подсказки E, разные именованные входы и Marker2D задают
переходы. Постоянный игрок и камера принадлежат корневой сцене, RoomHost
содержит ровно одну комнату. Во время перехода управление блокируется,
затем возвращается; guard выставляется до deferred-вызова, удержание E
не повторяет действие. Старые коллизии удаляются вместе с комнатой.
Глубина — свойство комнаты; HUD только отображает её, включая уменьшение
при возвращении. Находка запоминается до перезагрузки, без инвентаря.

Параметры движения и SpriteFrames героя сохранены. Новый живописный дальний
план, оригинальные SVG корней/растительности/входов и атмосфера продолжают
«Пепельный прилив». Источники и воспроизведение: [art-direction](art-direction.md).
Закрытое сплетение имеет физическую преграду. Его открытие после босса —
задача фазы 5; босса или фиктивной победы здесь нет.

## Проверки

Во время разработки: целевые suites `tests/route_test.gd`,
`tests/player_test.gd`, отдельный `tests/web/route.spec.cjs`, экспорт Web,
просмотр реальных Web-кадров. Проверка Web выявила, что selected-scenes
экспорт не включает новые сцены через script-preload: комнаты перечислены
явно во всех трёх пресетах, `dialogue.gd` включён отдельно. Проверка PCK
теперь требует все комнаты и диалог. На развилке предусмотрены уступы
с обеих сторон высокого корня для обратного маршрута.

Семь новых GdUnit4 tests: 3 реплики/закрытие/повтор диалога; близость NPC и
возврат управления; целостность всех связей; отклонение неверного/двойного
перехода; все точки появления без застревания/дублирования; глубина и
прыжки в обе стороны; сохранение находки и физически закрытый проход.

ветку/секрет, осматривает закрытый проход и возвращается на поверхность:
восемь переходов, один игрок, безопасные спавны, восстановление ввода,

## Скачать сборку и скриншоты

**[Открыть игру в браузере](https://cyberapalon.github.io/game2/)**.

Игра опубликована через GitHub Actions и Pages из публичного `cyberapalon/game2`.
Устанавливать Godot, Python или переносить файлы из Cloud не требуется.
Щёлкните по игре: A/D или стрелки — движение, Space — прыжок, E — взаимодействие.

[Первая успешная публикация](https://github.com/cyberapalon/game2/actions/runs/40401282144/attempts/2)
использует Godot 4.6.3 и исходники `0024f61742a0fb25f613df9e2c79051eb423b7ee`.
Владелец включил Source → GitHub Actions в Pages; job публикации повторён
с уже готовым artifact. HTTPS и контрольные суммы опубликованных файлов
проверены; полный Web-маршрут пройден на скачанной опубликованной сборке.
После обновления `main` сборка и публикация запускаются автоматически.
Детали: [GitHub Pages](pages.md).

Первоначальный способ выдачи через Release получил 401 от uploads.github.com,
а каталог файлов чата был read-only. Выдача Web-игры теперь выполнена через Pages.
Архивы Web, скриншотов и отчётов также подготовлены; доступ к игре обеспечивает
прямая ссылка выше. Скриншоты включают все комнаты и участки маршрута.

`tools/package_web.py` упаковывает проверенный build/manifest и отчёты;
`tools/play_web.py` — исходник локального запускателя. Скриншоты включают
поверхность, NPC, вход в шахту, спуск, все комнаты, находку, закрытый проход
и возвращение. В исходный Git не добавляются build/reports/ZIP.

Проверки Chromium/software WebGL подтверждают маршрут и ввод, но комфорт
на устройстве игрока остаётся ручной приёмкой. Windows runtime, Safari,
Firefox и мобильный ввод не проверялись. Звука, врагов, боя, здоровья,
смерти, прокачки, остальных биомов и сложных систем не добавлено.
