# Единый маршрут анимации и переменный прыжок

Доработка выполнена от main `4b64852` после художественного PR №5.
Весь существующий маршрут использует «Пепел и фарфор»: смотритель,
шахта, проходы, landing, junction, hollow, seal, платформы, земля,
параллакс, находка и закрытый свод. Восемь новых AI-исходников сохранены
в `assets/source/route`; подготовка — `tools/build_route_art.py`.
Исторические SVG не отображаются; inspector запрещает их в release PCK.

Герой использует девять частей одной рисованной иллюстрации. Корпус и маска
не меняют текстуру или масштаб; idle имеет только субпиксельное дыхание и
движение ткани. Кинематика ног ставит стопу в мировую опору, фаза зависит
от фактического пути. Никаких нарисованных программой геометрических конечностей
или попыток скрыть несовместимые кадры снижением FPS нет.

Раннее отпускание Space ограничивает оставшийся подъём до короткой дуги.
Полный импульс 500 px/s и gravity 1400 сохранены. Buffer и coyote — по 0.1 s,
потребление однократное, при блокировке/потере фокуса состояния очищаются.
Диалоги, секрет, коллизии, переходы и глубины сохранены. Враги, боёвка,
босс и новые биомы не добавлялись.

## Проверки и воспроизведение

```bash
source /workspace/.godot-cloud/env.sh
python3 tools/build_route_art.py
python3 tools/validate.py unit --suite res://tests/jump_test.gd
python3 tools/validate.py unit --suite res://tests/art_test.gd
python3 tools/validate.py build
GODOT_WEB_DIR="$PWD/build/web" playwright test --config tests/web/playwright.config.cjs route.spec.cjs quality.spec.cjs
python3 tools/validate.py all
python3 tools/build_review_media.py
```

Целевые проверки подтверждают высоты короткого/полного/среднего прыжка,
coyote после настоящего схода с уступа и истечение его окна, однократный
buffer, короткий buffered tap и отсутствие залипания после потери фокуса.
Все комнаты загружаются с PNG. Тестируется неизменность текстуры/масштаба
корпуса и неподвижность стоп при idle, а при беге — мировая координата опоры.
Два запуска извлечения дали одинаковые SHA-256 всех производных ресурсов.

Итоговый `python3 tools/validate.py all`, прогон `20261027T000905108727Z`:
29/29 GdUnit4 и 6/6 Web E2E, без ошибок, пропусков и flaky. Чистые экспорты
Web/Windows/Linux и Linux smoke прошли; release PCK содержит 124 ресурса
без SVG, addons и тестов. Main после проверки остался `4b64852`.

Web измерил короткий прыжок 52.14 px и полный 93.57 px. За 5.26 s наблюдения
idle корпус изменил высоту на 0.24 px, стопы оставались неподвижны.
На 16 проверенных интервалах опоры бега смещение стопы в мировых координатах
составило 0 px. Это измерения движения; художественная приёмка остаётся
за владельцем.

## Визуальная оценка

Записи получены из экспортированного Web реальными событиями клавиатуры.
CDP сохраняет кадры браузера и временные отметки; системный FFmpeg кодирует
MP4 без интерполяции. Все захваченные позы выводятся в покадровые листы
и просматриваются. У записей нет звуковой дорожки; звук самой игры сохранён.
Просмотрены все 138 захваченных кадров idle, 87 кадров бега и 57 кадров
прыжков. Маска, корпус и пропорции стабильны; грубых стыков и активных
графических заглушек в проверенных сценах не обнаружено.
Материалы включают 5.36 s idle, 3.44 s бега вправо/влево, сравнение двух
прыжков, поверхность с NPC, шахту, четыре комнаты, находку и закрытый проход.

Файлы не коммитятся в исходный Git: рабочие артефакты в `work/route-review`,
пользовательские файлы загружены в [материалы визуальной проверки](https://chatgpt.com/space/page_bc3ff35a484c8191880d06bc7d07fc90)
с подтверждённым доступом. Там находятся три MP4, десять PNG и JSON измерений.
Открытие страницы и встроенный видеоплеер в интерфейсе пользователя отдельно
не проверены; видео доступны обычными ссылками для открытия/скачивания.
Результат предназначен для визуальной оценки владельцем до следующей боёвки.
Windows runtime, аппаратная GPU-производительность и комфорт управления
на устройстве игрока отдельно не подтверждены; проверки Web идут в Chromium
с software WebGL. Версии движка и зависимостей не изменены.
